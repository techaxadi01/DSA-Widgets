Speed limit's 100. I'm on a motorcycle, law-abiding, never over it. You're on the roadside — no radar gun, just your eyes.

What can you tell me about my speed?

Think first — you never measured it. What's the one true thing you can say?

The witness's report
SPEED ≤ 100 km/h

Not the exact speed — an upper bound. Whatever it was, it never crossed 100.

That's Big-O

O(n) = "at most n" — a speed limit on running time, not an exact count. Same logic as the highway, just with a variable limit instead of a constant one.

O, Ω, and Θ aren't numbers you calculate — they're sets of functions. Saying f(n) ∈ O(n²) is like saying a car belongs to "vehicles that top out at 100." Flip through the other tabs for each set.

O(g(n)) — every function that grows no faster than g(n), eventually. The upper speed limit.

O(g(n)) = { f(n) : ∃ c, n₀ > 0 s.t. f(n) ≤ c·g(n) for all n ≥ n₀ }
g(n) = n² — who's in O(n²)?

Θ(g(n)) — functions boxed in on both sides: O(g(n)) ∩ Ω(g(n)). Neither faster nor slower.
