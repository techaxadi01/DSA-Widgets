struct Student {    int roll;    float marks;};struct Student s1 = {101, 87.5};struct Student s2 = {202, 92.0};struct Student *ptr;       // pointer declarationptr = &s1;                 // store address of s1printf("%d", ptr->roll);   // access through ptrptr = &s2;                 // point to s2 insteadprintf("%d", ptr->roll);   // now reads s2.roll
Key idea: A structure groups fields. A pointer lets us reach that structure indirectly using its address.

Dot vs arrow

s1.roll       // structure variable → dotptr->roll      // structure pointer → arrow(*ptr).roll    // equivalent to ptr->roll
