3Sum: sort and two pointers

LeetCode 15. Find all unique triplets that add up to 0. Step through the code and watch the three pointers move.

i (fixed number) left right

result (unique triplets found so far)






How it works


    

  • Sort first. Sorting costs O(n log n) and unlocks everything else. It places equal numbers side by side, so duplicates are easy to skip, and it tells us which pointer to move.
    • 

  • Fix one number, then solve a 2Sum. For each i, we need two numbers after it that add to -nums[i]. left starts just after i and right starts at the end.
    • 

  • Move by size. If the total is too small, only moving left right can raise it. If the total is too big, only moving right left can lower it. If it is 0, we record the triplet and move both.
    • 

  • Skip duplicates. We skip a repeated nums[i], and after a match we skip repeated values at left and right, so no triplet is recorded twice.
    • 

  • Why range(n - 2). The last two positions cannot start a triplet, because left and right need two more slots.
    • 

  • Cost. O(n²) time: n choices of i, and each two-pointer sweep is O(n). Extra space is O(1) apart from the output (plus whatever the sort uses).
    • 



Edge cases to try


Load 0, 0, 0, 0 (one triplet, not four), 1, 2, 3 (no triplet), -2, 0, 1, 1, 2 (duplicate 1s), and 0, 0 (too short, nothing happens).
