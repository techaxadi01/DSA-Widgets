Stack & Queue

Two containers. Opposite personalities.
📚 Stack
LIFO — Last In, First Out
empty
Stack ready. Push items onto it.
🚶 Queue
FIFO — First In, First Out
empty
Queue ready. Enqueue items into it.
🤔 Your browser's Back button — Stack or Queue?
When you visit A → B → C and press Back twice, you get C → B → A. That's LIFO.
🤔 A function calls itself endlessly, with no base case. What happens?
Each call pushes a frame onto the call stack. With no termination, the stack grows until memory runs out. Stack Overflow.
